## Performance interpretation and physical checklist

Art resource payloads are 1,722,112 bytes Classic / 6,888,448 bytes Enhanced;
both use 73 textures. Map/minimap RGBA backing targets are 12,720,000 / 50,880,000
bytes respectively. These are pixel payloads, excluding driver/glyph/allocator
overhead. Ownership expiry across switches verifies old complete art sets are
released; this is not a GPU-driver memory/leak certification.

Cold output/DPI/zoom transitions and warmed uncapped full-map redraws are recorded
separately. Warmed runs discard five frames then measure thirty; p95 is sample 29
of 30. Software rendering establishes correctness, not GPU performance acceptance.
Native hidden-window measurements exclude the compositor/physical display and do
not certify visible frame pacing or untested hardware.

Native Direct3D 11 acceptance passes, including twelve complete application
lifetimes, all scenarios and renderer recovery. This host reports Microsoft Hyper-V
Video / Microsoft Remote Display Adapter, one 100% display; it is not a physical
GPU/display acceptance machine. Warmed full redraw timings in milliseconds:
