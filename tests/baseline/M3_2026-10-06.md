  loop stops, all-playback mute/restart, volume bounds, 32 complete mixer lifetimes,
  invalid-device silent fallback and a real dummy-device playback object.

  stop while muted and earthquake sound/state behavior.

  funds, date, difficulty, graph history, tax/funding and muted preference. Saves
  do not mutate the live digest. Layout remains exactly 51,360 bytes with x-major
  tiles. Real locked-target replacement and nonexistent-parent creation failures
  preserve the original; a failed writer preserves both state and recovery.
- Invalid/missing/unsafe-speed/corrupt-tile/wrong-size loads retain the active city.
  Recovery saves create their isolated directory and restore the latest funds.
  Structured log records retain severity/code/path and keep multiline details in
  one quoted record. Test files are isolated temporary files, never repository
  city fixtures or real user data.
- Three injected startup failures exercise cleanup after window, graphics and UI
  ownership stages. Twelve complete SDL dummy/software application sessions run
  all eight scenario starts, simulation/message/generation/outcome checks, sprite
  draw/cache destruction/recreation, live timer creation/removal and recovery save/reload. Normal and exception

- All 25 M2 pre-extraction golden cases, including the 16,384-phase Detroit case,
  remain byte-for-byte expected digests. The engine include/import boundary,
